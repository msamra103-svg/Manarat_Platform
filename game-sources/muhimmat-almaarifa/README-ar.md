# مهمّة المعرفة

لعبة تعليمية ثلاثية الأبعاد تعمل في المتصفح. يقف الطالب في ميدان تدريب، يقرأ السؤال، ثم يصوّب ويطلق على الهدف الذي يحمل الإجابة. الإجابة الصحيحة تفتح بوابة المحطة التالية، والخاطئة تُنقص الصحة وتُبقيه في المهمة نفسها.

يختار اللاعب من الشاشة الرئيسية **مكان اللعب** (الصحراء أو الغابة) و**شخصيته** (مقاتل الصحراء، مقاتل الغابة، مقاتل الظل، أو الطالب الخليجي بالثوب والغترة). الاختيار يُحفظ في الجهاز.

الحزمة مستقلة تمامًا: لا تحتاج إنترنت أثناء اللعب، ولا اشتراكًا، ولا خادمًا خاصًا، ولا تعدّل أي منصة أخرى.

---

## ١) التشغيل

### أ. أسهل طريقة: ملف واحد بلا خادم

افتح الملف بالنقر المزدوج:

```
standalone/muhimmat-almaarifa-offline.html
```

يعمل بلا إنترنت وبلا أي تثبيت، ويمكن نسخه وحده إلى أي جهاز أو ذاكرة USB. كل شيء مضمّن داخله (نحو ٧ ميغابايت). الفرق الوحيد عن النسخة الكاملة أن خاماته بمقاس ٥١٢ فقط في كل مستويات الجودة.

### ب. النسخة الكاملة (مجلد `dist`)

هذه النسخة **لا تعمل بفتح `dist/index.html` مباشرة**؛ المتصفحات تمنع تحميل ملفات اللعبة من القرص دون خادم. شغّلها بإحدى الطريقتين:

- **ويندوز:** انقر مزدوجًا على `run-windows.bat`. يفتح اللعبة على `http://localhost:8080/` باستعمال PowerShell الموجود في ويندوز، دون تثبيت شيء. أبقِ النافذة السوداء مفتوحة أثناء اللعب.
- **ماك / لينكس:** نفّذ `./run-mac-linux.sh` (يستعمل Python 3 أو Node.js).

### ج. النشر على استضافة ثابتة

ارفع **محتويات** مجلد `dist` إلى أي مجلد على استضافتك (مثل `https://example.com/games/muhimmat/`). كل المسارات نسبية، فلا حاجة لأي إعداد. جُرّب التشغيل من داخل مجلد فرعي.

## ٢) طريقة اللعب

| الجهاز | التصويب | الإطلاق | أخرى |
|---|---|---|---|
| الحاسوب | تحريك الفأرة | النقر | الأرقام ١–٤ تختار هدفًا وتطلق عليه، الأسهم تدير النظر، المسافة تطلق، Esc للإيقاف المؤقت |
| الهاتف واللوح | السحب بالإصبع | زر الإطلاق، أو لمس الهدف مباشرة | زر الإيقاف المؤقت أعلى الشاشة |

- الذخيرة غير محدودة ولا يوجد مؤقّت.
- الطلقة التي لا تصيب هدفًا لا تُحسب.
- الهدف الخاطئ الذي أُصيب يتعطّل، فلا يُخصم منه مرتين.
- بعد التصويب باللمس أو بالأرقام يعود النظر إلى الوسط تلقائيًا حتى تبقى الأهداف كلها ظاهرة.
- عند نفاد الصحة تظهر مراجعة للسؤال مع خيار الاستكمال من المهمة نفسها بصحة كاملة.

القواعد الافتراضية: الصحة ١٠٠، الخطأ يخصم ٢٠، والنقاط ١٠٠ / ٧٠ / ٤٠ / ١٠ بحسب رقم المحاولة.

### المكان واللاعب

| الاختيار | ما يتغيّر |
|---|---|
| **الصحراء** | رمال وكثبان ونخيل، وحصن جصّي بطابع خليجي. |
| **الغابة** | أرض عشبية وأشجار بلوط ودردار وصنوبر، وحصن حجري، وصدى أقصر وأكتم للطلقات. تُحمَّل أصولها عند أول اختيار فقط. |
| **مقاتل الصحراء / الغابة / الظل** | النموذج نفسه بثلاثة أزياء لونية، وتتبدّل معه الذراعان في منظور الشخص الأول. |
| **الطالب الخليجي** | ثوب أبيض وغترة وعقال، ويدان مكشوفتان بكُمّي الثوب في منظور الشخص الأول. شخصية مبسّطة مبنية بالشيفرة. |

المنطق والأسئلة والنقاط واحدة في كل الأماكن ومع كل الشخصيات.

## ٣) لوحة المعلم

من الشاشة الرئيسية: **لوحة المعلم**.

- **الأسئلة:** إضافة وتعديل وحذف، مع تحديد الإجابة الصحيحة، والتفسير، وتلميح اختياري، ونص مشكول اختياري للقراءة الصوتية.
- **استيراد / تصدير JSON:** إذا كان الملف المستورد معيبًا تظهر المشكلات بالعربية ويبقى البنك السابق كما هو.
- **قواعد اللعب:** الصحة، الخصم، نقاط كل محاولة، عدد أسئلة الجلسة، خلط الخيارات والأسئلة، مدة عرض التفسير.
- كل شيء يُحفظ في المتصفح على الجهاز نفسه. إذا تعذّر الحفظ (وضع التصفح الخاص مثلًا) يظهر تنبيه وتبقى التغييرات حتى إغلاق الصفحة.

### صيغة ملف الأسئلة

ملف نموذج جاهز للتعبئة: `dist/questions/import-template.json`، والأسئلة التجريبية: `dist/questions/demo-questions.json`.

```json
{
  "title": "عنوان البنك",
  "questions": [
    {
      "id": "q-001",
      "text": "نص السؤال؟",
      "options": [
        { "id": "a", "text": "خيار" },
        { "id": "b", "text": "خيار آخر" }
      ],
      "correctOptionId": "a",
      "explanation": "تفسير قصير للإجابة",
      "hint": "تلميح اختياري",
      "speech": "نَصٌّ مَشْكُولٌ اختياري للقراءة الصوتية"
    }
  ]
}
```

قواعد التحقق: من خيارين إلى أربعة لكل سؤال، معرّفات غير مكررة، إجابة صحيحة واحدة موجودة ضمن الخيارات، لا نصوص فارغة، لا خيارات متطابقة في السؤال نفسه. الحد الأقصى ٢٤٠ حرفًا للسؤال و٩٠ حرفًا للخيار، وهو ما يضمن ظهور النص كاملًا على لوحة الهدف بخط مقروء.

الإجابة الصحيحة مرتبطة بالمعرّف `correctOptionId` لا بموضع الخيار، فخلط الترتيب لا يغيّرها.

### تغيير الأسئلة الافتراضية نهائيًا

عدّل `src/data/demo-bank.json` ثم أعد البناء (القسم ٥).

## ٤) الإعدادات داخل اللعبة

- **جودة الرسوم:** تلقائية / منخفضة / متوسطة / عالية. الوضع التلقائي يختار بحسب الجهاز، وينزل درجة إذا قاس أقل من ٢٧ إطارًا في الثانية لعدة ثوانٍ. شاشة الإعدادات تعرض المعدل المقاس فعلًا.
- **ثلاث قنوات صوت مستقلة:** أصوات اللعب والمؤثرات، أجواء الميدان، القراءة الصوتية.
- **القراءة الصوتية** اختيارية ومطفأة افتراضيًا. تستعمل صوت الجهاز العربي إن وُجد؛ هي قراءة آلية وليست تسجيلًا بشريًا، وجودتها تتبع الجهاز. تعذّرها لا يمنع اللعب.
- **تقليل الحركة واهتزاز الكاميرا**، و**حساسية تحريك النظر**.

## ٥) التعديل والبناء (للمطوّر)

المتطلبات: Node.js 18 أو أحدث.

```bash
npm install
npm run dev      # خادم تطوير
npm run build    # ينتج dist/ ثم standalone/
npm run assets:trees   # (اختياري) يعيد توليد أشجار الغابة بمكتبة ez-tree
npm test         # اختبارات منطق اللعب وبنك الأسئلة
```

الاختبار الآلي الكامل في متصفح حقيقي (يحتاج Python و Playwright و Chrome):

```bash
node tools/serve.mjs dist 8080 &
python3 tests/e2e.py http://localhost:8080/
```

### بنية المشروع

```
src/core/      منطق خالص بلا رسوم: القواعد، الجلسة والنقاط، بنك الأسئلة، التخزين
src/gfx/       الرسوم: الميدان وأماكنه، الأهداف، السلاح واليدان، الشخصيات، المؤثرات، تحميل الأصول
src/audio/     توليد الأصوات والقراءة
src/input/     الفأرة واللمس ولوحة المفاتيح
src/ui/        الشاشات، واجهة اللعب، لوحة المعلم
src/data/      الأسئلة التجريبية
public/assets/ النموذج والخامات (مقاسان: 1k و 512)
tools/         تجهيز الخامات، توليد الأشجار، الخادم المحلي، صانع ملف التشغيل الواحد
tests/         اختبارات الوحدة والاختبار الآلي الكامل
docs/          قائمة الأصول والتراخيص، تقرير الاختبار، لقطات من اللعبة
```

بنك الأسئلة ومنطق اللعب مفصولان: `src/core/session.js` لا يعرف شيئًا عن الرسوم، وكل طرق الاختيار (فأرة، لمس، لوحة مفاتيح) تمر عبر دالة تقييم واحدة.

### استبدال الخامات أو الشخصية

- ضع الخامات الأصلية في مجلد ثم نفّذ: `python3 tools/prepare_assets.py <المجلد> public/assets/textures` (الأسماء المتوقعة داخل السكربت).
- الشخصية: استبدل `public/assets/models/soldier.glb` بنموذج له هيكل Mixamo وحركة باسم `Idle`. الطالب الخليجي مبني على الهيكل نفسه، فيبقى يعمل.
- إضافة شخصية أو مكان: أضف سطرًا إلى `CHARACTERS` في `src/gfx/characters.js` أو إلى `ENVS` في `src/gfx/world.js`.

## ٦) نقاط ربط مستقبلية (اختيارية)

اللعبة تعمل مستقلة، وهذه النقاط لا تُستعمل إلا إذا استعملتها المنصة المستضيفة:

1. **تحميل بنك أسئلة من رابط:** `index.html?bank=questions/my-bank.json`. يُتحقق من الملف بالقواعد نفسها، وإن كان معيبًا تُستعمل الأسئلة المحفوظة ويظهر تنبيه.
2. **أحداث الجلسة:** تُرسَل على `window` كحدث، وإلى الصفحة الأم عبر `postMessage` إذا كانت اللعبة داخل إطار:
   - `mm:session-start` وفيه `{ total, bankTitle, environment, character }`
   - `mm:session-end` وفيه `{ playerName, bankTitle, result }` حيث `result` يحوي النقاط، ونسبة الصحيح من المحاولة الأولى، وعدد الأخطاء، وتفصيل كل سؤال.

```js
window.addEventListener('message', e => {
  if (e.data && e.data.source === 'muhimmat-almaarifa' && e.data.type === 'session-end') {
    console.log(e.data.detail.result);
  }
});
```

لم تُدمج اللعبة في أي منصة ولم تُنشر عليها.
