# سباق الخيل — قفز الحواجز — `horse-jumping-race`

لعبة تعليمية ثلاثية الأبعاد بالعربية على نمط «سباق الهجن القطري»: سباق خيل على مضمار عشبي فيه حواجز (أسيجة أغصان). يجري الحصان تلقائيًا، وقبل كل حاجز يظهر سؤال والسباق كله متجمد:

- **إجابة صحيحة** ← يقفز الحصان الحاجز (ومن أول محاولة ينال اندفاعة في المقطع التالي).
- **إجابة خاطئة** ← **يرفض الحصان الحاجز**: يكبح ويتوقف أمامه، يستدير ويعود قليلًا ثم يقترب من جديد، والمنافسون يواصلون. يُعاد السؤال نفسه مع تعطيل الاختيار الخاطئ. **لا يتخطى الحصان الحاجز إلا بعد الإجابة الصحيحة.**

> حزمة مستقلة للمراجعة. لم يتم أي تعديل على المنصة المنشورة أو مستودعها أو قاعدة بياناتها، ولا تحتاج اللعبة إلى تسجيل دخول أو مفاتيح سرية.

---

## ١. التشغيل السريع

**أ) النسخة الجاهزة (بدون إنترنت وبدون خادم):** افتح `dist/index.html` بالنقر المزدوج في Chrome أو Edge. كل المكتبات والخطوط والنماذج مضمّنة.

**ب) محاكي المنصة (يتطلب خادمًا محليًا):**
```
cd dist-platform-sim
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080/` — صفحة مضيفة تحمّل اللعبة من `games/horse-jumping-race/` وتربطها عبر `postMessage`.

متصفح حديث يدعم WebGL2. على الأجهزة الأبطأ اختر «جودة منخفضة» أو اترك «تلقائية».

## ٢. البناء من المصدر
```
npm install
npm run build        # ينتج dist/ و dist-platform-sim/
npm test             # اختبارات منطق السباق والربط (Node)
npm run sculpt       # (اختياري) إعادة توليد شبكات الحصان والفارس والمتفرجين المنحوتة
```

## ٣. الإعدادات القابلة للتعديل بعد البناء
| الملف | الغرض |
|---|---|
| `game.config.js` | زمن الجري بين الحواجز (٤–٨ ث)، عدد المنافسين، الصعوبة، مقدار الاندفاعة، الجودة، تقليل الحركة، قنوات الصوت الثلاث، المؤقت الاختياري، نوع الربط والمصادر المسموح بها |
| `questions.sample.js` | **بيانات تجريبية** (٦ أسئلة) مع مفتاح إجابة للمحاكي المحلي فقط |

معاملات رابط اختيارية: `?segment=5&difficulty=easy&quality=low&mode=classroom&questions=4&timer=30&reducedMotion=1`

بنية السؤال كما في لعبة الهجن (`id`, `type: 'mcq'|'tf'`, `text`, `choices[{id,text}]`, `media` اختياري). الإجابة تُربط بمعرّف الاختيار لا بموضعه.

## ٤. قواعد اللعب والعدالة
1. شاشة البداية ← لقطة افتتاحية مع نفير البوق ← عد تنازلي ٣ ثوانٍ مرة واحدة.
2. جري ≈٦ ثوانٍ نحو الحاجز ← نقطة السؤال (قبل الحاجز بـ٧ م) ← سؤال واحد والجميع متجمد.
3. صحيح ← قفزة. خطأ ← رفض (≈٢٫٨ ث يتقدم فيها المنافسون) ثم السؤال نفسه دون الاختيار الخاطئ.
4. بعد آخر حاجز: اندفاع ختامي ≈٤ ثوانٍ نحو خط النهاية ← النتائج.

- **عدد الحواجز = عدد الأسئلة** (٦ افتراضيًا)، ولا يتكرر سؤال.
- **النقاط منفصلة عن المركز:** ١٠ نقاط للصحيحة من أول محاولة، ٥ من الثانية، ولا نقاط بعدها. المركز يحدده السباق نفسه.
- **خيول المنافسين ترفض أحيانًا أيضًا** (كما في سباقات الحواجز الحقيقية) بعدد حتمي يتبع الصعوبة: سهل ٢–٤ حواجز، متوسط ١–٣، صعب ٠–٢ لكل منافس. بذلك يكون التدرّج عادلًا: خطأ واحد لا يُسقطك للمؤخرة، وكثرة الأخطاء تُنزل المركز تدريجيًا.
- من يجيب عن الكل صحيحًا من أول محاولة يفوز في كل المستويات؛ والفوز ليس تلقائيًا (خطأ في كل حاجز لا يفوز).
- خط النهاية يُثبَّت لحظة تطبيق آخر إجابة صحيحة وأمام المتصدر، فلا يعبره أحد قبل ذلك. ترتيب النتائج = ترتيب العبور الفعلي.
- الإيقاف المؤقت وإخفاء التبويب يجمّدان كل شيء دون قفزة زمنية. الضغط المتكرر لا يسجّل إلا إجابة واحدة.

**الوضع الصفي:** فريق واحد، أزرار أكبر، تناوب الطلاب، والمعلم يضغط «متابعة السباق» بعد التغذية الراجعة. اختصارات: `1`–`4` للإجابة، `Esc`/`P` للإيقاف.

## ٥. بنية المشروع
```
src/
  race/raceModel.js           منطق السباق الحتمي: الحواجز، نقطة السؤال، الرفض، العدالة، خط النهاية — بلا رسوم
  horse/
    horseAnatomy.js           مفاصل الهيكل العظمي وألوان الخيل (كُميت، أشقر، أشهب، أدهم، ...)
    horseBuilder.js           الهيكل العظمي + الشبكة المكسوّة + العُرف والذيل + قماش السرج + اللجام
    horseSculpt.js / .data.js الشبكة المنحوتة (مولَّدة) وتلوينها ومادة الشعر اللامع
    horseAnimator.js          العدو الإجرائي + IK للأرجل + حركة القفز (ارتقاء، طيران، هبوط)
    jockey.js / .data.js      الفارس المنحوت بوضعية السباق وتأرجحه مع الحصان
    horse.js                  كيان الحصان في المشهد (مع العنان وظلال التماس)
  scene/                      المضمار العشبي والحواجز، المدرج والجمهور، البيئة، الإضاءة، الكاميرا، المعالجة اللاحقة
  ui/  audio/  integration/   الواجهة العربية، قنوات الصوت الثلاث، طبقة الربط (محاكي محلي + postMessage)
  game/gameController.js      آلة الحالات وتنسيق كل ما سبق
tools/sculpt/                 النحت التشريحي (حقول مسافية) للحصان والفارس والمتفرجين
tests/                        اختبارات Node + اختبارات المتصفح (Playwright)
docs/                         التراخيص، تقرير الاختبارات، لقطات، فيديو
```

## ٦. الربط بالمنصة
راجع `INTEGRATION_CONTRACT_AR.md`. العقد **مقترح** (نفس عقد لعبة الهجن `qcr-bridge/1` مع حقل `attemptNo`)، ويجب مطابقته مع عقد المنصة المعتمد عند الدمج.

## ٧. ما يجب معرفته قبل الاعتماد
- **الحصان والفارس والجمهور** منحوتون تشريحيًا داخل المشروع (ليست مسوحًا ثلاثية الأبعاد ولا خامات فوتوغرافية). التفاصيل في `docs/ASSETS_AND_LICENSES.md`.
- **الأصوات مولّدة إجرائيًا:** وقع الحوافر على العشب، الصهيل، حفيف الأغصان عند القفز، شهقة وهتاف الجمهور، نفير البوق. ليست تسجيلات حقيقية وتحتاج مراجعة سمعية بشرية.
- التعليق الصوتي العربي يعتمد على صوت النظام (Web Speech)؛ إن لم يتوفر تعمل اللعبة بالمؤثرات فقط.
- تفاصيل ما اختُبر وما لم يُختبر: `docs/TEST_REPORT_AR.md`.
