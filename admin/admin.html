يحتاج دالة Supabase باسم send-whatsapp-message وSecrets خاصة بـ WhatsApp Cloud API. إذا لم تكن مفعلة، يمكن للنموذج الرجوع لفتح واتساب بالطريقة العادية.

🤖 إعدادات الذكاء الاصطناعي Gemini

تم ضبط التوليد الذكي ليعمل عبر Supabase Edge Function الآمنة لقراءة ملفات PDF بثبات أكبر، مع بقاء التوليد المباشر كاحتياطي عند الحاجة.

انسخ هذه القيم كما هي عند الإعداد الآمن:
اسم الدالة الحالية: dynamic-handler
اسم السر في Supabase: GEMINI_API_KEY
النموذج: gemini-2.5-flash

الوضع الحالي: التوليد يعمل عبر Edge Function فقط. ضع مفتاح Gemini في Supabase Secret باسم GEMINI_API_KEY، ولا تضعه داخل ملفات الموقع.

☁️ إعدادات قاعدة البيانات Supabase

بيانات Supabase مدمجة داخل هذه النسخة ومفعلة افتراضيًا. استخدم Project URL و Publishable/Anon Key فقط، ولا تضع Service Role Key داخل المنصة.

المطلوب نسخه من Supabase:
1) Project URL
2) anon/public أو publishable key
3) تشغيل ملف supabase/00_START_HERE_CREATE_DATABASE.sql مرة واحدة من SQL Editor

إذا فشل الاختبار: تأكد من صحة الرابط والمفتاح، ثم شغّل ملف supabase/00_START_HERE_CREATE_DATABASE.sql الوحيد داخل SQL Editor.

🧰 النسخ الاحتياطي والاسترجاع

صدّر نسخة كاملة من المنصة أو استورد نسخة احتياطية وادمجها مع البيانات الحالية. تشمل النسخة: الهوية، التواصل، الألعاب، المعلمين، البنوك، النتائج، الرسائل، وسجل العمليات.

مهم: عند الاستيراد يتم الحفاظ على إعدادات Supabase والذكاء الاصطناعي الحالية، حتى لا يتغير الربط الشغال.
