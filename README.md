# منارة التعلم الرقمي — V17

منصة تعليمية رقمية عربية تجمع بين الألعاب التعليمية التفاعلية، معرض الفيديوهات، أدوات الذكاء الاصطناعي، حسابات المعلمين، النتائج والتقارير.

## الإصدار الحالي

**17.0.0 — Premium Experience**

أبرز تحديثات V17:
- إعادة تصميم الصفحة الرئيسية بالكامل.
- Design System موحد للرئيسية، الدخول، لوحة المعلم، منشئ الألعاب، الأدمن، وشاشة اللعب.
- قسم فيديوهات YouTube احترافي مع تشغيل مباشر وصور مصغرة.
- تحسين تجربة الجوال والتنقل.
- تحسين تسلسل المحتوى والـCTA.
- ربط Supabase الجديد بالحساب الإداري الصحيح.
- تفعيل RLS للجداول الأساسية.
- نشر Edge Functions الخاصة بالذكاء الاصطناعي، YouTube، واتساب، وإدارة المستخدمين.
- إضافة فحص Smoke Check لمنع رجوع إعدادات الحساب القديم.

## البنية

- `index.html` — الصفحة الرئيسية.
- `auth.html` — تسجيل الدخول وإنشاء الحساب.
- `teacher/` — لوحة المعلم ومنشئ الألعاب.
- `admin/` — لوحة إدارة المنصة.
- `player/` — مشغل الألعاب.
- `css/main.css` — الأنماط الأساسية.
- `css/v17.css` — نظام التصميم الجديد.
- `js/core.js` — الحالة والربط السحابي والمصادقة.
- `js/home.js` — منطق الصفحة الرئيسية.
- `supabase/` — قاعدة البيانات وEdge Functions.

## التحقق

شغّل:

```bash
node scripts/smoke-check.js
```

لفحص الملفات الأساسية وصياغة JavaScript والتأكد من عدم رجوع بيانات Supabase أو البريد الإداري القديم.
