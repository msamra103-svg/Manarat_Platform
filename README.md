# مدرسة أبو عبيد الإعدادية للبنين — V19.1

منصة عربية للتعلم بالألعاب والفيديو، مبنية على منصة منارة ومستودعها الحالي.

## التشغيل

- الصفحة الرئيسية: دخول المعلم أو الانضمام برابط/رمز المهمة.
- المعلم: إنشاء حساب باسم مستخدم فريد وكلمة مرور، دون إدخال بريد إلكتروني.
- المدير: يدخل بالبريد وكلمة المرور الحاليين؛ لم يتم تغيير حسابه.
- إنشاء لعبة يفتح محرر الأسئلة الحالي، ثم «إسناد وتشغيل» لاختيار القوالب وأنواع الأسئلة والصف وموعد الإغلاق.
- تشغيل جماعي: يُسجل جلسة للمعلم دون درجات فردية. التشغيل الفردي والواجب المنزلي: اسم الطالب ودرجته وتغذيته الراجعة.
- سجل الإنجاز: تصحيح المقال، تصحيح الاسم/ربط المحاولات يدويًا، وتصدير CSV عربي يفتح في Excel.
- هوية المدرسة: الاسم والشعار والألوان والنصوص والأقسام وروابط التواصل، مع معاينة ومسار استعادة.

## الألعاب وحدود الإصدار

السباق يستخدم المحرك ثلاثي الأبعاد السابق مع أسئلة المهمة. بازل الصور يستخدم محرك السحب والتركيب السابق. كرة القدم أصبحت مشهدًا فوتوغرافيًا متحركًا داخل ملعب مستوحى من لوسيل، مع سؤال في منتصف التسديدة وهدف أو صد أو خروج للكرة وأصوات جمهور. الشخصيات صور مولدة متحركة وليست تصويرًا للاعبين حقيقيين. بقية القوالب الرياضية وكشف الصورة هي مشاهد تعليمية مبسطة مرتبطة بصحة الإجابات، وليست محركات رياضية ثلاثية الأبعاد. السباق يحتاج WebGL. لم تُجرَ تجربة ضغط بمئة معلم متزامن ولا اختبار على سبورة مدرسية فعلية.

## النشر والصيانة

المستودع: msamra103-svg/Manarat_Platform. المشروع: yltlzogrhwvnmxcnaesu. الواجهة تستخدم المفتاح العام فقط. أسرار الخدمة تبقى في Supabase.

على قاعدة قائمة، نفذ بالترتيب `supabase/01_UPGRADE_V17_1.sql` ثم `supabase/02_SCHOOL_V19.sql` وانشر دوال `supabase/functions`. لا تستخدم ملف إنشاء قاعدة جديدة فوق قاعدة موجودة. دالة school-api تتحقق بنفسها من هوية المعلم وصلاحياته؛ تحتاج verify_jwt=false للسماح بمسار الطالب دون حساب. جداول المدرسة لا تُقرأ مباشرة من المتصفح.

الاستضافة تنشر مجلد `public`. يجب مزامنة أي تعديل في js/css/assets/games/teacher/admin/player والصفحات الجذرية إلى public قبل النشر؛ `npm run check` يكتشف اختلاف الملفات.

روابط ألعاب منارة القديمة العامة لا تُستخدم كتقييمات مدرسية؛ أنشئ روابط المهمات الجديدة من لوحة المعلم، لحماية مفاتيح الإجابة. المحتوى القديم وحساب المدير محفوظان.

## التحقق

`npm ci` ثم `npx playwright install chromium` ثم `npm test` باستخدام Node 24.
اختبارات V19 تشمل صلاحيات المعلم، حماية مفاتيح الإجابة، التصحيح على الخادم، الاستعادة، التصدير، أحجام الشاشة، وتشغيل السباق والبازل. اختبارات المتصفح المحلية تستخدم بيانات محاكاة؛ اختُبرت أيضًا فعليًا دورة حساب معلم مؤقت → لعبة → مهمة → طالب → درجة محفوظة، ثم أُزيلت بيانات الاختبار.

التوليد الذكي ورفع الفيديو يحتاجان إعدادات الخدمة والمساحة المتاحة في الحساب. لم يُختبر توليد فعلي مدفوع أو تحميل فيديو كبير في هذه الجولة. حماية كلمات المرور المسرّبة غير مفعلة في إعدادات الحساب؛ التوصية: https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection

## تحديث كرة القدم V19.1

التجربة المباشرة: `games/football/index.html` (تدريب فقط دون حفظ الدرجات). من مهمة المعلم: اختر كرة القدم لتستخدم أسئلة المهمة وتصحيح الخادم والتقرير الحالي. الأسئلة المقالية قيد التصحيح تظهر نتيجة محايدة دون منح هدف أو اعتبارها خاطئة. الصوت يبدأ بعد دخول الملعب ويمكن كتمه؛ تعمل اللعبة دون WebGL.

فحص اللعبة: `npm run test:football`. لا يتطلب التحديث تغيير قاعدة البيانات.

## حركة القدم والسلة V19.3

- تغيّر تشغيل كرة القدم إلى مشهد WebGL ثلاثي الأبعاد بشخصيات مفصلية أصلية: اقتراب، ثني الركبة، تماس القدم مع الكرة، متابعة الركلة، ارتماء الحارس وهبوطه وتعافيه. هذه شخصيات ألعاب ثلاثية الأبعاد وليست تصويرًا بشريًا أو نماذج ممسوحة ضوئيًا. خلفية المدرجات تستعمل جزءًا من صورة الملعب السابقة، وليست إعادة بناء هندسية دقيقة لاستاد لوسيل.
- كرة السلة: أرضية خشبية، مدرجات، تنطيط، قفز وإطلاق الكرة من اليد، مسار مقوّس، حلقة وشبكة متحركة، نقطتان لكل إجابة صحيحة، وارتداد عند الخطأ.
- تستخدم اللعبتان الأسئلة والتصحيح الخادمي نفسه في روابط المهمات. المقالية تبقى محايدة إلى اعتماد المعلم. الأصوات السابقة للجمهور باقية؛ أصوات الاصطدام والصافرة والتنطيط والشبكة مولدة محليًا.
- الروابط التدريبية: `games/football/index.html` و`games/basketball/index.html`. تحتوي الأسئلة التجريبية فقط؛ روابط مهمات المعلم تستخدم أسئلته وتسجّل النتائج.
- الفحص: `npm run test:sports` للمفاصل والإحداثيات ومسار الكرة وتسلسل حالات اللعب وحماية الرسائل. فُحص كذلك school-api ولوحة الإدارة وفحص ملفات النشر. لم تُجرَ في هذه الجولة معاينة GPU/متصفح فعلية أو تجربة على آيفون حقيقي؛ دعم WebGL شرط للتشغيل، وتظهر رسالة واضحة عند عدم توفره.

## صالة البولينج V19.4

التجربة: `games/bowling/index.html`. داخل مهمات المعلم اختر البولينج لتشغيل أسئلتك وحفظ درجات الإجابة. تتحكم في موضع الوقوف والزاوية والقوة والدوران، ويمكن توجيه الرمية باللمس على المسار. محاكاة اصطدامات حتمية تحسب سقوط القوارير؛ الإجابة الصحيحة لا تضمن سترايك. الإجابة الصحيحة تتيح إضافة القوارير الساقطة إلى نقاط اللعب المحلية، بينما تقارير المنصة تعتمد درجة الإجابة.

النمط تدريب تعليمي بعشر قوارير جديدة لكل سؤال، وليس نظام الأشواط التنافسي الكامل. المحاكاة تقريبية وليست محرك أجسام صلبة ثلاثي الأبعاد معتمدًا. تُستخدم مكتبات وأصول محلية دون CDN. الاختبار: `npm run test:bowling`. لم تُجرَ معاينة GPU/متصفح فعلية أو تجربة على آيفون حقيقي في هذه الجولة.
