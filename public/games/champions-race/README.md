# سباق الأبطال ثلاثي الأبعاد — نسخة الطلاب (متعددة الملفات)
الإصدار 8.0.0 — 2026-10-19

## ما الجديد في هذا الإصدار
- طريق حقيقي منحني (Catmull-Rom) تتشارك فيه الرسوميات والتصادم مسارًا واحدًا، مع منعطفات خفيفة ومتوسطة وحادة، وحواجز حماية وعلامات.
- سيارات رياضية PBR حقيقية (Ferrari 458 Italia وGT كونسبت) مع دهان Clearcoat وزجاج وعجلات تدور وتنعطف ومحوّل اتجاه المقدمة.
- فيزياء قيادة بتحكم حقيقي بالتوجيه، ومنافسون يتجاوزون ويتفادون، وكاميرات متعددة.
- ثماني مدن مستوحاة (الدوحة، القاهرة، دبي، الرياض، لندن، باريس، إسطنبول، نيويورك) + مدينة مخصصة.
- كل نظام الأسئلة محفوظ كما هو (نعم/لا، اختيار من متعدد، حواجز مادية، تلميحات، نقاط، كأس، استيراد وتصدير).
- يعمل بالكامل دون إنترنت: لا CDN ولا خطوط خارجية ولا نماذج أو أصوات أو واجهات برمجية بعيدة.

## ملفات الحزمة
- `index.html` (النسخة ذات الملف الواحد): كل شيء مضمّن في ملف واحد. انقر عليه مرتين لتشغيله.
- النسخة المتعددة الملفات: `index.html` + `app.js` + `vendor/` + `assets/` — يجب إبقاء المجلدات بجانب الملف.
- `CREDITS_AND_LICENSES.txt`: الاعتمادات والتراخيص.

## التشغيل
- Windows / Mac / Linux: افتح الملف في Chrome أو Edge أو Firefox أو Safari. اختُبر آليًا في Chromium مع حجب الشبكة بالكامل.
- Android: افتح الملف عبر Chrome (لم يُختبر على جهاز فعلي).
- iPhone / iPad: **لم يُختبر على جهاز فعلي ولا نؤكد عمل `file://` على iOS**. يقيّد iOS فتح صفحات HTML المحلية؛ الحل الموثوق هو رفع الملف إلى استضافة HTTPS (GitHub Pages أو Netlify أو Vercel أو خادم المدرسة) ثم فتحه في Safari وإضافته للشاشة الرئيسية، أو تغليفه في تطبيق WebView (مثل Capacitor) إن لزم العمل دون اتصال تمامًا.
- السبورة الذكية: افتحه في Chrome/Edge؛ فعّل «وضع أداء الفصل» إن كان الجهاز ضعيفًا.

## نسخة المعلم
زر «لوحة المعلم» يحوي: بنك الأسئلة، هوية المدرسة، إعدادات السباق (المدينة، السيارة، اللون، الجودة، المنافسون، الصعوبة، حساسية التوجيه، التسارع التلقائي، نمط اللمس، خصم الاصطدام، المسافة بين الحواجز، الصوت، وضع أداء الفصل)، فحص الأصول، والتصدير. من تبويب «التصدير» يمكنك توليد نسخة الطلاب (ملف HTML واحد مستقل أو ZIP) بدون لوحة المعلم وبكل أسئلتك وإعداداتك.
للتصدير ينبغي استخدام نسخة الملف الواحد (أو تشغيل النسخة المتعددة الملفات عبر خادم).

## الترقية من الإصدار V7
تُحفظ أسئلتك وإعداداتك كما هي. تُكتب نسخة احتياطية تلقائية من سجلك القديم قبل الترقية، ويمكن استرجاعها من «لوحة المعلم ← التصدير والنسخ الاحتياطي».
