| File | Origin | Licence |
|---|---|---|
| `BarramundiFish.glb` | Khronos Group *glTF-Sample-Assets* repository, model **BarramundiFish** (mesh + PBR textures, published 2017, donated by Microsoft) — https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/BarramundiFish | CC0 1.0 Universal (public-domain dedication) |

`tools/export.html` loads this file, normalises it, reshapes the body proportions per species and repaints the
colour texture (hamour / shaari / safi). The resulting `assets/models/fish-*.glb` are therefore derivative works of a
CC0 asset; attribution is not legally required but is given here and in `docs/LICENCES_V24.md`.
