# دمج صيد الأسماك V24.1

دُمجت حزمة `AbuUbaida-Fishing-V24.1.zip` في النسخة الحالية من منصة مدرسة أبو عبيدة الإعدادية للبنين، بناءً على طلب المالك في 27 أكتوبر 2026.

## نطاق الدمج

- استُبدلت لعبة الصيد القديمة باللعبة المستقلة الجديدة، مع النماذج الستة، الأصوات العشرين، الأدوات المصدرية وملفات التراخيص.
- بقيت واجهة رسائل `school-fishing-*` كما هي. تتولى المنصة عرض الأسئلة وتصحيحها وحفظ نتائجها؛ اللعبة تعرض نتيجة التصحيح فقط.
- لم تُستبدل الملفات المشتركة أو الألعاب الأخرى بنسخ الحزمة القديمة. أُضيفت أوامر اختبار الصيد إلى `package.json` مع الاحتفاظ باختبارات المسابقة المباشرة.
- أُعيد توليد ملفات النشر باستخدام أداة المزامنة المعتادة.

## إصلاحات المراجعة

- اختيار جودة الرسوميات يُطبَّق قبل بداية الجلسة الحالية، ويعيد تجهيز المشهد دون تغيير أسئلة المهمة أو بيانات اتصال اللعبة بالمنصة.
- القيم غير الصالحة لجودة الرسوميات تعود إلى الاختيار التلقائي، مع تحرير هدف الانعكاسات والظلال عند التخلص من المشهد.
- عدّاد السؤال يعرض ترتيب الأرقام الصحيح داخل الواجهة العربية.
- اختبار التصدير المستقل يقبل مسارًا نسبيًا، وتدعم اختبارات المتصفح متغير `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
- حُفظ مرجع الحزمة الأصلية في `SOURCE_MANIFEST.json` و`SOURCE_PACKAGE.json` داخل هذا المجلد؛ يتحقق اختبار العزل من عدم استبدال المصادر المشتركة أو أوامر الاختبار السابقة.

## التحقق

تشمل اختبارات الصيد الفيزياء، توقّف السمكة أثناء السؤال، الصيد الصحيح مرة واحدة، الإفلات، انتظار التصحيح اليدوي، حماية الرسائل، نماذج GLB، الصوت والتشغيل المستقل.

يختبر `tests/fishing-school-browser.cjs` صفحة الطالب الفعلية وملف `js/school.js` باستخدام استجابات API معزولة، بما فيها فشل حفظ النتيجة مرة ثم إعادة المحاولة دون تكرار الإجابات. لا ينشئ هذا الاختبار طلابًا أو درجات في قاعدة الإنتاج.

اختبارات المتصفح تستخدم Chromium مع رسم WebGL برمجي وسبعة مقاسات شاشة؛ قياسات الأداء في هذه البيئة ليست قياسات لأداء الأجهزة الفعلية أو Safari.

```sh
npm run test:fishing
npm run test:fishing:browser
node tests/game-session.cjs
node tests/game-modes.cjs
node tests/school-api.cjs
npm run build
```

تحتفظ نسخة `file://` المستقلة بأسئلة تدريب محلية فقط؛ لا تصل إلى بنوك أسئلة المنصة ولا تسجّل درجات رسمية.
