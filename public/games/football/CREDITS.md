# Football — sources, licences and attribution (V22)

Everything in this folder is either generated by this project's own code, derived from CC0 sources, or a CC0 recording. No real clubs, kits, players, broadcasts or logos are used. The stadium is an original design *inspired by* modern Gulf stadium architecture; it is not a reproduction of any specific stadium.

## 3D characters (athlete / runner / keeper)
- Base human mesh and the target/morph data: **MakeHuman** community assets, released under **CC0 1.0** (public domain dedication). Source: https://github.com/makehumancommunity/makehuman — commit `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`; see `LICENSE.md` §C and `LICENSE.ASSETS.md`; the `base.obj` header states "explicitly released as CC0 in september 2020".
- Everything built from it is produced by the scripts in `tools/football-assets/` (`build_body.py`, `build_character.py`, `mh_common.py`): body shaping, 26-bone skeleton and skin weights, kit regions (jersey / shorts / socks / boots / gloves), ambient occlusion, UVs, LOD, and the exported `characters/*.json|bin`.
- Skin textures (`characters/textures/skin_*.jpg`) and the eye texture (`eye_brown.png`) are painted procedurally by those scripts. No photographs and no scans of real people.
- Kits (burgundy home `#8A1538`, away, goalkeeper, referee) and the shirt numbers are drawn on canvas at runtime by `engine/fb-kit.js`. The crest is an original school-style shield.

## Boots (V22)
- The football boots are generated meshes (lofted heel counter, collar, toe box and flat sole fitted to each foot's measured extents) produced by `append_boots()` in `tools/football-assets/build_character.py` and skinned to the foot bones. Original code; no third-party model.

## Animation
- No motion-capture library or clip is used (V22 included). Walking, running, turning, the kick (approach → plant → swing → contact → follow-through), first touch, the goalkeeper's ready stance / dive / rise and celebrations are **procedural**: world-space two-bone IK on the skeleton (`engine/fb-rig.js`, `fb-anim.js`, `fb-keeper.js`). Original code, no third-party animation data.

## Stadium, net, crowd, effects
- Pitch, stands, roof, floodlights, scoreboard, LED boards (Arabic school messages), net and crowd are generated geometry and canvas textures (`engine/fb-stadium.js`, `fb-net.js`, `fb-crowd.js`, `fb-fx.js`). No external texture or model is loaded.
- Legacy images `assets/stadium.png` and `assets/players.png` are AI-generated for this project earlier (see the previous credits below). `stadium.png` is still used by the shared sports/volleyball scenes; **the new football page does not load either image**.

## Audio
- Layered ambience, chants/claps, whistle, boot and pass contact, post/bar/net/glove hits, goal and near-miss reactions are **synthesised at runtime with Web Audio** (`engine/fb-audio.js`). No third-party recording.
- `assets/crowd-cheer.mp3` — “Crowd Cheer II” by FoolBoyMedia, **CC0**, https://freesound.org/people/FoolBoyMedia/sounds/397435/ (HQ preview).
- `assets/crowd-miss.mp3` — “crowd oh - disappointed” by mrrap4food, **CC0**, https://freesound.org/people/mrrap4food/sounds/619007/ (HQ preview).

## Code and fonts
- Rendering: `games/vendor/three.min.js` (three.js r128, MIT) — already shipped with the platform.
- Fonts: system Arabic fonts only (Tajawal if installed locally, else platform default). No web-font download.
- Icons: inline SVG drawn for this project.

## Previous version (V19.x), kept for history
Stadium and player atlas were AI-generated for this project with the built-in image generation tool (photographic simulation inspired by Lusail Stadium; not a photograph of a real match or identifiable professional players). `football.js` (the former 2.5D renderer) is retained in the folder but no longer loaded by `index.html`.
