# حزمة المصدر الأصلية لكرة السلة V23.1 — مدرسة أبو عبيدة الإعدادية للبنين

هذه الحزمة مأخوذة من المستودع الفعلي للمنصة وليست نموذجًا مُعاد كتابته.
المستودع: https://github.com/msamra103-svg/Manarat_Platform
معرّف نسخة المصدر: ea399ee2ea0bd24a18b4823c7d84f4b7d41e0026

## طريقة الاستخدام
1. نزّل هذا الفرع كملف ZIP من GitHub.
2. ارفع ZIP إلى Claude.
3. انسخ إليه نص الملف CLAUDE_MASTER_PROMPT.md.
4. اطلب حزمة تطوير كاملة مع المصدر والأصول والاختبارات، لا صورًا أو مجرد تعديلات شكلية.
5. بعد الانتهاء، أعد حزمة Claude لمراجعتها ودمجها داخل منصة أبي عبيدة.

## الملفات
- games/basketball: كامل المصدر الحالي والصور والخامات والنماذج ثلاثية الأبعاد والخطوط والجمهور.
- games/vendor/three.min.js: مكتبة Three.js المشتركة (مرجع لا يُستبدل).
- js/platform-nav.js وpackage.json: ملفات مرجعية للربط، لا تُستبدل داخل المنصة.
- tests/basketball-* وdocs/basketball-upgrade وtools/basketball-assets: الاختبارات والوثائق والأدوات.
- SOURCE_MANIFEST.json: أسماء الملفات وبصماتها وأحجامها.

## تنبيه مهم
الفرع المخصّص للتصدير ليس فرع تطوير ولا يُدمج مباشرة في main.
تُنسخ ملفات كرة السلة المطوّرة إلى مستودع المنصة الأصلي ثم يُعاد إنشاء public عبر build.
بعض أصوات الجماهير الاختيارية تعود إلى ملفات كرة القدم ولم تُدرج هنا بسبب ضرورة التحقق من ترخيصها.
