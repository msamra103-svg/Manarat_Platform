# حزمة تطوير صيد الأسماك — منصة ألعاب أبي عبيدة

هذه نسخة مصدر من لعبة **صيد الأسماك** الفعلية في المستودع:
https://github.com/msamra103-svg/Manarat_Platform
مرجع النسخة: 7828f379927dd857d8c33a40a072859a75d2b3aa
المدخل الحالي: games/fishing/index.html

## ملاحظة هندسية بالغة الأهمية
تستخدم اللعبة ملفات games/experiences/* المشتركة مع ألعاب الكرة الطائرة والبازل وغيرها.
وتستخدم كذلك games/sports/athlete.js؛ لذا فإن تغيير تلك الملفات مباشرة قد يسبب خللًا في الألعاب الأخرى.

المطلوب أن يُنشئ كلود محركًا مستقلًا للعبة صيد الأسماك داخل games/fishing/*
ويترك ملفات التجارب المشتركة وبقية المنصة كما هي.

## الاستخدام
1. نزّل هذا الفرع من GitHub كملف ZIP.
2. ارفع الملف إلى Claude أو امنحه رابط الحزمة مع صلاحية قراءة الملفات كلها.
3. اطلب تنفيذ CLAUDE_FISHING_V24_MASTER_PROMPT.md الموجود بداخلها.
4. احصل على مصدر لعبة مطوّر كامل وأصوله واختباراته في ZIP.
5. أعد الحزمة لإجراء المراجعة قبل دمجها في منصة أبي عبيدة.

النسخة المرجعية لا تحتوي على مجلد public المكرر؛ يُعاد توليده بواسطة npm run build / scripts/sync-public.js عند الدمج.

لم يُنشر أي تعديل للإنتاج بهذه الخطوة. هذه حزمة تطوير وتسليم فقط.
