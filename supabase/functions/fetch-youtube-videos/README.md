# fetch-youtube-videos

دالة اختيارية لجلب آخر فيديوهات قناة يوتيوب عامة من رابط القناة أو handle.

## الاسم المطلوب

`fetch-youtube-videos`

## الإعداد

- يمكن جعل Verify JWT = OFF لأنها تقرأ بيانات عامة فقط.
- لا تحتاج Secrets.
- تستخدم RSS الرسمي للقناة:
  `https://www.youtube.com/feeds/videos.xml?channel_id=...`

من لوحة الأدمن:
- ضع رابط القناة.
- اضغط "جلب آخر 5 فيديوهات من القناة".
- رتّب الفيديوهات ثم اضغط حفظ الصفحة الرئيسية.
