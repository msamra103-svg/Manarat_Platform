# dynamic-api

هذه هي دالة حذف المعلم/المعلمة من Supabase Auth حسب الرابط الحقيقي الموجود عندك:

`/functions/v1/dynamic-api`

مع أن الاسم الظاهر في Supabase قد يكون `delete-user-admin`.

## مهم
- لا تغيّر دالة الذكاء الاصطناعي `dynamic-handler`.
- اترك Verify JWT = ON.
- الكود يجب أن يكون داخل ملف `index.ts`.
