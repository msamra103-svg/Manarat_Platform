# صيد الأسماك V24.1 — Licences and asset origins

Every asset shipped in `games/fishing/` is listed below. Two public-domain (CC0) sources are used as the starting point of the realistic angler and fish; everything else is original work for this project. No photographs, fonts or sound recordings are bundled, and nothing is downloaded from the internet at runtime.

## 3D models — `assets/models/`

The GLB files are written by `tools/build-assets.cjs` (headless Chromium + three.js `GLTFExporter` r128). Licence of the project-made parts: owned by the project / school (same terms as the rest of the Manarat_Platform repository).

| File | Content | Origin / licence |
|---|---|---|
| `boat.glb` | 5.4 m fibreglass fishing skiff: lofted hull with gel-coat, boot stripe, antifouling and weathering, gunwales, teak deck, seats, unbranded outboard, ice box with hinged lid, tackle box, bait bucket, rod holder, fenders, life ring | original — `js/models/boat-model.js` |
| `fisherman.glb` | Realistic adult male angler: skinned mesh (32 k triangles) on a 66-bone skeleton, eyes and cornea, painted short hair / beard, long-sleeve shirt, life jacket, trousers, deck shoes | **derived from MakeHuman 1.x CC0 assets** (base mesh `hm08`, macro modifier targets, default skeleton + weights, high-poly eyes and eye texture; repository makehumancommunity/makehuman, commit a8bc2d5) processed by the project's own `tools/makehuman/build_fisherman.py`; garments, skin/hair painting and shoes are original. MakeHuman assets licence: **CC0 1.0 Universal** (text: `tools/makehuman/LICENSE.ASSETS-MakeHuman-CC0.md`). The face is a parametric average, not based on any real person. |
| `tackle.glb` | Spinning reel (rotor, bail, spool, crank, knob), rod grip & reel seat, line guide, sliding float, sinker, hook with shrimp bait, telescopic landing net | original — `js/models/tackle-model.js` |
| `fish-hamour.glb` | هامور — orange-spotted grouper (*Epinephelus coioides*) | **derived from Khronos glTF-Sample-Assets “BarramundiFish” (CC0 1.0, donated by Microsoft, 2017)** — mesh reshaped to the species' proportions and colour texture repainted by `tools/export.html`; normal / roughness maps from the source. See `tools/source-assets/README.md`. |
| `fish-shaari.glb` | شعري — spangled emperor (*Lethrinus nebulosus*) | same source and process |
| `fish-safi.glb` | صافي — white-spotted rabbitfish (*Siganus canaliculatus*) | same source and process |
| `embedded-models.js` | Base64 copy of the six GLB files above (for offline `file://` use) | generated by `tools/build-assets.cjs` |
| `manifest.json` | Sizes / triangle counts / origin of the models | generated |

Fallbacks: if a GLB cannot be loaded, the game rebuilds simplified original models from `js/models/fisherman-model.js` / `fish-model.js` (original work).

Species representations follow published colour patterns of the named Gulf species on a shared perciform body; the rabbitfish in particular keeps a perch-like body outline (disclosed in the changelog). Displayed weights are computed from the GLB body volume × 1050 kg/m³ and labelled as a simulation estimate; they are not biological measurements.

## Sound — `assets/audio/`

All sounds are **original procedural synthesis** written for this project (`js/audio-dsp.js`: seeded noise, filters, oscillators, bell partials, Karplus–Strong plucked strings). `tools/build-audio.cjs` renders them to 32 kHz / 16-bit mono WAV; the game can also re-render them in the browser. No recordings or samples from any library are used. Licence: owned by the project.

## Fonts, images, logos

No font files are shipped; the interface uses system fonts (Noto Kufi Arabic / Segoe UI / Tahoma fallback). No logos are drawn: the boat stripe uses the school colour maroon `#8A1538` only. The skyline on the horizon is a generic arrangement of boxes and cylinders, not a replica of any specific building. Screenshots in `docs/screenshots/` are real captures of the running game (software WebGL), not generated artwork.
