# Basketball motion preview V22

This is a motion prototype, not a completed photoreal character upgrade. The existing procedural athletes remain visible. Do not present this preview as equivalent to the licensed car models in Champions Race V8.

Implemented: basketball-specific scene isolated from football; gravitational shot trajectory; continuous transition at the question and hoop; elastic floor bounces; rim deflection; dribble-height-driven arm joints; damped camera; maroon presentation. Existing trusted-parent question and assessment bridge is unchanged.

Required art dependency: an authorized male basketball athlete GLB (preferred), with textures, skin weights, skeleton and ideally dribble, gather, jump-shot, land, defend and celebrate animations. No licensed third-party model has been copied into this branch. The repository does not contain a suitable realistic character, and reviewed public listings do not establish an accessible rigged download usable here. Static posed people are not acceptable substitutes for animated athletes.

Tests: node tests/basketball-motion-v22.cjs; node tests/basketball-scene-v22.cjs; npm run test:sports; npm run build. Full browser visual acceptance of the new basketball scene remains outstanding. Keep this branch as a preview until character art and motion are approved.
