# البنية التقنية — عدّاء قطر

Three.js r128 (النسخة نفسها المستخدمة في المنصة `games/vendor/three.min.js`)، WebGL، JavaScript عادي دون أدوات بناء؛ كل الأصول داخل الحزمة ولا تعتمد على أي رابط خارجي.

## الوحدات

| الملف | الدور |
|---|---|
| `js/config.js` | الإعدادات الافتراضية، التحقق، الحفظ في `localStorage` بمفتاح خاص (`qatarRunner.config.v1`)، الأسئلة التجريبية، خلط الإجابات (Fisher–Yates) مع حفظ موضع الصحيحة |
| `js/boy-data.js` | نموذج الولد المضغوط (يولّده `tools/pack-boy.cjs`) |
| `js/boy.js` | بناء الشخصية + قماش الثوب والغترة + محرك الحركة |
| `js/tex-data.js` | خامات PBR (لون/نتوء/خشونة/إضاءة ليلية) يولّدها `tools/textures/build_env.py` ويحزمها `tools/pack-tex.cjs` |
| `js/textures.js` | خامات مرسومة برمجيًا (أسفلت، حواف أرصفة، بلاط، حجر السوق، طين، نخيل، واجهات، نقش البوابة، علم قطر، لافتات عربية، أمواج) |
| `js/props.js` | نماذج أصلية: سيارات، شاحنة، مخروط، حواجز، عارضة، عربة، صناديق، سجادة، نخلة، إنارة، علم، شجيرات، مقاعد، مظلات، فوانيس، داو، عملة |
| `js/world.js` | السماء وتدرج النهار/الليل، الإضاءة والظلال، الماء، أبراج الخليج الغربي والمئذنة الحلزونية، تدفق المقاطع (٢٠ م) للكورنيش والسوق، حركة السير |
| `js/track.js` | توليد العوائق والعملات بعدالة، صناديق التصادم، سقوط الحواجز عند الاصطدام |
| `js/gate.js` | بوابة السؤال الذكية، الموجة، الجسيمات، قوس النهاية والقصاصات |
| `js/audio.js` | الصوت والموسيقى المولّدان (Web Audio) |
| `js/game.js` | آلة الحالات، الفيزياء، الكاميرا، الإدخال، الواجهة، جسر المنصة، خطافات الاختبار |
| `js/teacher.js` | لوحة المعلم والتصدير |

## الشخصية (ثبات الهوية)
- **الجسم**: `tools/makehuman/build_boy.py` يقرأ بيانات MakeHuman 1.x (CC0): الشبكة الأساسية hm08 مع أهداف «طفل ١١ سنة» ونِسب مثالية وطول ١٫٤٧ م، الهيكل الافتراضي وأوزانه، العينان عاليتا الدقة. تُرسم خامة البشرة (لون قمحي، حواجب، شفاه) والثوب والسروال في فضاء UV من الموضع ثلاثي الأبعاد. الوجه متوسط إحصائي لأهداف MakeHuman وليس صورة لشخص حقيقي.
- الهوية تُبنى **مرة واحدة**: الحركة تدور العظام وتحاكي القماش فقط، ولا تبدّل الشبكات أو المواد في أي حالة (يتحقق منه الاختبار ١١).
- **القماش**: محاكاة Verlet بخطوات ثابتة (١٨٠ هرتز، ٤ تكرارات): الجزء العلوي من الغترة مثبت على عظمة الرأس، والطرف المتدلي يصطدم بملف الجذع الحقيقي المقاس من الشبكة وبكبسولات الرقبة والذراعين؛ الثوب مثبت على الحوض ويصطدم بكبسولات الساقين مع **تصادم أحادي الجانب** يمنع القماش الأمامي من العبور خلف الساق السريعة، وقيود مسافة قصوى (tethers) تمنع التطاير غير الطبيعي، وتنعيم للعرض فقط.
- **الحركة**: مشية/جري بتوقيت وطول خطوة مرتبطين بالسرعة، القدم مثبتة أثناء الارتكاز (تتحرك مع الأرض)، مسار تأرجح بمنحنى Catmull-Rom، IK ثنائي العظمة للساق بقطب أمامي (الركبة لا تنثني للخلف أبدًا)، دوران الحوض والجذع المعاكس، ذراعان بزاوية مرفق تتبع السرعة، مزج الحالات بتلاشٍ قصير.

## آلة الحالات
```
menu → intro → run ──(اقتراب البوابة)──> approach ──(توقف ومركز المسار)──> question → evaluate
      ↑                                                                        ├─ صحيحة → success (تفتح، يعبر) → run
      │                                                                        └─ خاطئة → reject (موجة) → recover → retry → approach
      │                                                  نفاد القلوب → gameover → (إعادة من البوابة | من البداية)
آخر بوابة → finish (قوس النهاية، فرح) → results → شهادة
```
كل التوقيتات داخل حلقة التحديث (لا مؤقتات `setTimeout` قد تنطلق في حالة لاحقة)، وكل إجابة محمية بقفل، والبوابة المغلقة جدار في الفيزياء.

## العدالة في التوليد
لكل صف ثلاث خانات: حرة / قفز / انزلاق / حجب. يُحسب عدد المسارات التي يمكن للاعب قطعها منذ الصف السابق (٠٫٣ ث لكل مسار)، ويُضمن وجود مسار عابر ضمن المجموعة القابلة للوصول، مع مسافة دنيا ≈ ١٣ م، ومنع العوائق قبل البوابات بـ ٩٥ م وبعدها بـ ٣٢ م. تظهر العوائق على بعد ~٢٤٠ م فلا شيء «يقفز» أمام اللاعب.

## الصورة الواقعية
- سماء فيزيائية (نموذج Preetham) مع غبش أفق الدوحة، وانعكاسات بيئية منها.
- عرض بمرحلتين داخل هدف عرض متعدد العينات ثم تمرير لوني فوتوغرافي (منحنى S، تلوين الظلال/الإضاءات، تشبّع، تعتيم حواف، توهّج خفيف، تنعيم) — في الجودة العالية والمتوسطة فقط.
- مواد PBR بخرائط نتوء وخشونة، زجاج عاكس، طلاء سيارات بطبقة لامعة، قماش بلمعة ناعمة، بشرة بتشتت تحت السطح.

## الأداء
- عرض بمرحلتين (الخلفية البعيدة بكاميرا مدى بعيد، ثم القريب) لدقة العمق.
- الأشياء المتكررة كلها `InstancedMesh` يُرسم منها فقط الجزء المستخدم.
- الجودة: عالية (ظلال ناعمة 2048، DPR≤2)، متوسطة (ظلال 1024، DPR≤1.5)، منخفضة (دون ظلال، DPR 1، قماش أخف). تخفيض تلقائي لدقة العرض إذا انخفضت الإطارات عن ~٢٦.
- القياس في المتصفح البرمجي (منخفضة): ~٢٢٠ ألف مثلث و~١٥٠ نداء رسم في الكورنيش، ومنطق+حركة+قماش ≈ ٥ مللي ثانية للإطار. **لم تُقَس معدلات الإطارات على أجهزة حقيقية بعد.**

## المسارات المضمّنة
وضع مستقل (أسئلة المعلم المحلية) — وضع المنصة (`school-qatar-runner-*`) — ملف واحد دون إنترنت مع تصدير نسخة الطالب.
