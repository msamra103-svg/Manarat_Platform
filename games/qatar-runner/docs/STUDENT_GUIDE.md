# دليل الطالب — عدّاء قطر

أنت العدّاء! اجرِ في كورنيش الدوحة وسوق واقف، واجمع العملات، وافتح بوابات الأسئلة بإجاباتك.

| الحركة | لوحة المفاتيح | الشاشة اللمسية |
|---|---|---|
| تغيير المسار | ← → أو A D | اسحب يسارًا / يمينًا |
| القفز فوق الحواجز المنخفضة | ↑ أو W أو المسافة | اسحب للأعلى |
| الانزلاق تحت العوارض | ↓ أو S | اسحب للأسفل |
| اختيار الإجابة | ١ ٢ ٣ ٤ | المس الإجابة |
| إيقاف مؤقت / كتم الصوت | P / M | الأزرار أعلى الشاشة |

- **السيارات والعربات** لا يمكن القفز فوقها — غيّر المسار.
- **البوابة المضيئة**: يتوقف الولد ويظهر السؤال. الإجابة الصحيحة تفتح الجناحين وتمنحك نقاطًا؛ والإجابات الصحيحة المتتالية تضاعف النقاط (×٢، ×٣…).
- **الإجابة الخاطئة** تردّك موجة ضوئية للخلف وتخسر قلبًا ❤، ثم تحاول من جديد.
- عند خط النهاية تظهر نتيجتك، ويمكنك طباعة **شهادة الإنجاز**.
