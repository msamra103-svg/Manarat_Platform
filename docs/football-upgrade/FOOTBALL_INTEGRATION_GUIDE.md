# Football upgrade — integration guide, attribution list, acceptance checklist

## 1. Apply safely (no deploy, no push, no database change)
The ZIP is an **overlay**: only changed and new files, with their repository paths, plus these documents, `changes.diff` and screenshots.

```bash
git checkout -b football-ultra-realism          # work on a branch, never on main
unzip AbuUbaida-Football-Realism-Upgrade.zip -d /tmp/football-overlay
cp -R /tmp/football-overlay/overlay/. .          # copies over the same paths
npm run sync                                     # refreshes public/ mirrors
npm run check                                    # syntax/reference/mirror check
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm run test:football
git status                                       # review; then open a pull request yourself
```
- `changes.diff` is a plain unified diff of every text file (binaries listed in `FILES.txt`). `git apply --check -p1 changes.diff` shows whether it applies to your tree.
- The upgrade needs **no database migration, no edge-function change and no new environment variable**. `.env` and `node_modules` are not in the ZIP.
- Roll back by discarding the branch. Nothing outside `games/football/`, one `js/school.js` line, an appended CSS block, `package.json` (one script) and docs/tests was touched.

## 2. Preview locally
```bash
node scripts/preview-football.js 8080
# open http://127.0.0.1:8080/games/football/
```
Flags: `?mode=light|standard|pro`, `?diff=0|1|2`, `?q=0|1|2` (graphics tier), `?reduced=1`, `?lite=1`, `?debug=1`, `?demo=long`, `?manual=1`. A browser with WebGL is required for the 3D view; without it the page offers the simplified mode. Teacher assignments use the normal platform flow (`/?task=<code>`), which embeds the same page in the iframe.

## 3. What to check in the platform after merging
1. Open an assignment with the football template; the question appears as a broadcast panel over the frozen match.
2. Answer correctly → goal and score +1; wrong → save/miss; essay → neutral "وصلت إجابتك".
3. Basketball, volleyball, bowling and fishing assignments still look and behave as before (their dialogs do not get the football skin).
