# الجولات الصفية للألعاب التعليمية

أصبح التشغيل الجماعي يبدأ بجولة صفية سريعة، مع إمكانية اختيار تجربة اللعبة الكاملة. ويمكن الانتقال من اللعبة الكاملة إلى الجولة السريعة مع الاحتفاظ بالإجابات المصحّحة. عند تعذّر WebGL تستخدم الألعاب التي تعتمد عليه الجولة الخفيفة تلقائيًا.

| اللعبة | ما أضيف للاستخدام داخل الصف |
| --- | --- |
| تحدّي المعرفة | تفسير بعد الإجابة وملخص للأفكار التي تحتاج مراجعة |
| بازل الصور | حفظ فوري عند اكتمال القطع، إعادة الحفظ عند فشل الاتصال، نقاش حول الصورة |
| سباق السيارات | محطات مباشرة دون انتظار القيادة، تصحيح اسم المدرسة عند بدء اللعبة |
| كرة القدم | سؤال ثم تسديدة سريعة وتناوب الفرق |
| كرة السلة | تسديدة مرئية خفيفة دون اشتراط WebGL |
| الكرة الطائرة | تمرير الدور بعد السؤال والتوقف للنقاش |
| البولينج | مشهد قوارير وحركة مباشرة بعد التصحيح |
| صيد الأسماك | السؤال متاح فورًا ومشهد ثابت لجمع السمكة |
| التصويب على الهدف | بالونات واختيارات باللمس أو الأرقام، ورسالة أدق لفشل الرسوم |
| عدّاء قطر | بوابات درس مباشرة وتسليم الدور بين الفرق |
| مغامرات بطل قطر | محطات دون التنقل، فرصة للتصحيح، نسبة تقدّم لتحميل اللعبة الكاملة |
| سباق الهجن | مسار يتوقف بين الأسئلة للنقاش والمتابعة اليدوية |
| سباق الخيل | إعادة المحاولة مع فصل النجاح الأول عن التصحيح اللاحق |
| مهمّة المعرفة | مستكشف ببطاقات مباشرة، تفسير عند الخطأ، وإلغاء خصم الطاقة في اللعب الجماعي الكامل |

تدعم الجولات حتى ستة فرق وسؤال نقاش ختامي. تبقى أسماء الفرق وملاحظات الجولة في الجلسة الحالية، بينما يستمر حفظ النتائج التعليمية بواسطة واجهة المدرسة الحالية. لا تضيف الجولة درجات فردية في اللعب الجماعي.

تعرض اللوحة النقاط التعليمية، ودقة الإجابة من أول محاولة، وعدد الأسئلة المكتملة كلًا على حدة. يظهر التقدير النهائي من الخادم عند نهاية المهمة. إعادة الإجابة الصحيحة بعد الخطأ في ألعاب البطل والخيل ومهمّة المعرفة تمنح صفر نقاط إضافية، كما يقرر الخادم.

## التحقق

- اكتملت تجارب الألعاب الأربع عشرة في المتصفح حتى ملخص النتائج، بما فيها تركيب قطع البازل التسع بلوحة المفاتيح.
- اختُبرت الإجابة الخاطئة ثم التصحيح في ألعاب البطل والخيل ومهمّة المعرفة، وتناوب فريقين ووقفة النقاش والإجابة بالأرقام.
- تغطي اختبارات `test:classroom` الانتقال أثناء المهمة، ومنع تكرار النقاط، ودقة المحاولة الأولى، والتصحيح المؤجل، وإعادة البدء، واستئناف السؤال غير المحسوم، وسلامة النصوص المعروضة.
- نجحت اختبارات البناء والصلاحيات وواجهة المدرسة وقاعدة البيانات وواجهات الخادم ومحركات الألعاب المتاحة دون متصفح.
- تعذّر تشغيل حزمة اختبارات Chromium المحلية بسبب قيود تشغيل المتصفح. اختبارات الرسوم ثلاثية الأبعاد على جهاز فعلي ما زالت مطلوبة، ويُستخدم المتصفح السحابي لاختبار الجولات الخفيفة.
